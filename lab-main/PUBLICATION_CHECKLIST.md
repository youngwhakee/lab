# KEE LAB v0.1 공개 전 체크리스트

현재 패키지는 '먼저 공개하고 점진적으로 채우는' 용도의 프리뷰 버전입니다.

공개 전에 최소 확인:
- [ ] 교수님 성함 표기가 정확한지
- [ ] 학교/학과 표기가 정확한지
- [ ] 공개하면 안 되는 개인 정보가 없는지
- [ ] 샘플 데이터가 실제 정보로 오인될 소지가 없는지
- [ ] 공식 이메일과 연구실 위치는 확인 전까지 placeholder 상태인지

사이트 공개 후 우선 교체:
- [ ] 교수님 프로필 사진
- [ ] Biography / Education / Career
- [ ] 현재 Members
- [ ] Publications
- [ ] Alumni
- [ ] News
- [ ] Gallery 사진
- [ ] Contact 정보
